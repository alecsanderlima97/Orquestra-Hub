# Orquestra Hub

Sistema SaaS modular para gestao financeira, operacional e comercial de pequenos negocios.

## Modulo inicial

Financeiro para controle de lojas, fornecedores, compras, parcelas, contas a pagar e baixas de pagamento.

## Tecnologias

- Next.js App Router
- TypeScript
- Tailwind CSS
- Firebase

## Rodar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.
